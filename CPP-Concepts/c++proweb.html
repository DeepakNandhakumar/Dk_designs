C++ PROGRAMMING

Introduction

C++ is the most used and most popular programming language developed by Bjarne Stroustrup. C++ is a high-level and object-oriented programming language. This language allows developers to write clean and efficient code for large applications and software development, game development, and operating system programming. It is an expansion of the C programming language to include Object Oriented Programming (OOPs) and is used to develop programs for computers. This C++ Tutorial will cover all the basic to advanced topics of C++ like C++ basics, C++ functions, C++ classes, OOPs and STL concepts.

What is C++?

C++ is a popular cross-platform programming language used to create high-performance applications and software like OS, games, and e-commerce software. It was developed by Bjarne Stroustrup as an extension of the C language, providing a high level of control over system resources and memory.

C++ Basics

C++ is a general-purpose, object-oriented programming language developed in 1979 by Bjarne Stroustrup at AT&T Bell Laboratories. It is a high-level programming language and an advanced version of C. Compared to other programming languages like Java and Python, C++ is known for its speed.

Syntax

Syntax refers to the rules and regulations for writing statements in a programming language. These rules define the structure of a programming language. C++ has specific syntax rules that must be followed for writing different statements.

Example of C++ syntax:

C++ Data Types

All variables use a data type during declaration to restrict the type of data they can store. Data types specify the size and type of values to be stored. C++ supports a wide variety of data types, which can be classified into three main categories:

  • Primitive Data Types
  • Derived Data Types
  • User-defined Data Types

Primitive Data Types

  • Integer (int): Requires 4 bytes of memory, ranges from -2147483648 to 2147483647.
  • Character (char): Requires 1 byte of memory, ranges from -128 to 127 or 0 to 255.
  • Boolean (bool): Stores logical values (true or false).
  • Floating Point (float): Requires 4 bytes of memory for single-precision decimal values.
  • Double Floating Point (double): Requires 8 bytes of memory for double-precision decimal values.
  • Void: Represents a valueless entity, used for functions that do not return a value.
  • Wide Character (wchar_t): Used for larger character sets, typically 2 or 4 bytes long.

C++ Variables

Variables in C++ are names given to memory locations. They are the basic units of storage in a program. The value stored in a variable can be changed during program execution. All operations done on a variable affect that memory location. In C++, all variables must be declared before use.

How to Declare Variables?

A typical variable declaration is of the form:

        
            // Declaring a single variable
            type variable_name;

            // Declaring multiple variables
            type variable1_name, variable2_name, variable3_name;
