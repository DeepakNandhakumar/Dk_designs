Strings in C++

C++ strings are sequences of characters stored in a char array. They are used to store words, text, and other types of data.

C Style Strings

These are stored as arrays terminated by a null character '\0', inherited from C language.

// Example of C-style strings
          #include <iostream>
          using namespace std;
      
          int main() {
              char s[] = "GeeksforGeeks";
              cout << s << endl;
              return 0;
          }
          // Output: GeeksforGeeks

std::string Class

Introduced in C++, it offers dynamic size and member functions.

// Example of std::string class
          #include <iostream>
          using namespace std;
      
          int main() {
              string str("GeeksforGeeks");
              cout << str << endl;
              return 0;
          }
          // Output: GeeksforGeeks

Ways to Define a String

Strings can be defined using 'string' keyword or C-style character arrays.

// Examples of string definition
          #include <iostream>
          using namespace std;
      
          int main() {
              // Using string keyword
              string s = "GeeksforGeeks";
              cout << "s = " << s << endl;
      
              // Using C-style strings
              char s1[] = { 'g', 'f', 'g', '\0' };
              cout << "s1 = " << s1 << endl;
      
              return 0;
          }
          // Output:
          // s = GeeksforGeeks
          // s1 = gfg

How to Take String Input in C++

Input methods include 'cin', 'getline', and 'stringstream' for reading strings.

// Example of string input using getline
          #include <iostream>
          using namespace std;
      
          int main() {
              string s;
              cout << "Enter String" << endl;
              getline(cin, s);
              cout << "String is: " << s << endl;
              return 0;
          }
          // Output:
          // Enter String
          // String is: (user input)

C++ String Functions

Function Description
length() Returns the length of the string.
swap() Swaps the values of two strings.
size() Returns the size of the string.
resize() Resizes the string to the specified number of characters.
find() Finds the first occurrence of a substring.
push_back() Appends a character to the end of the string.
pop_back() Removes the last character from the string.
clear() Clears the string, removing all characters.
strncmp() Compares the first num bytes of two strings.
strncpy() Copies at most n bytes of the source string.
strrchr() Finds the last occurrence of a character in the string.
strcat() Appends a copy of the source string to the destination string.
replace() Replaces a portion of the string with another string.
substr() Returns a substring from the string.
compare() Compares two strings and returns an integer result.
erase() Erases a portion of the string.

C++ Strings Iterator Functions

Function Description
begin() Returns an iterator to the beginning of the string.
end() Returns an iterator to the end of the string.
rfind() Finds the last occurrence of a substring.
rbegin() Returns a reverse iterator to the beginning of the string.
rend() Returns a reverse iterator to the end of the string.
cbegin() Returns a const_iterator to the beginning of the string.
cend() Returns a const_iterator to the end of the string.
crbegin() Returns a const_reverse_iterator to the beginning of the string.
crend() Returns a const_reverse_iterator to the end of the string.
