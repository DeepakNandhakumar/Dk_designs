Functions

Functions are a fundamental building block in C++ programming that allow you to break down complex problems into smaller, manageable tasks. They enable code reusability and better organization.

Function Declaration and Definition

A function must be declared before it is used in a program. A function declaration tells the compiler about a function's name, return type, and parameters. The function definition provides the actual body of the function.


// Function declaration
int add(int a, int b);

// Function definition
int add(int a, int b) {
  return a + b;
}

Calling Functions

Once a function is declared and defined, it can be called from any part of the program. When calling a function, provide the necessary arguments.


int result = add(5, 3);  // Function call
std::cout << "Result: " << result << std::endl;

Returning Values from Functions

Functions can return values using the return statement. The return type of the function must match the type of value returned.


double multiply(double x, double y) {
  return x * y;
}

double product = multiply(4.5, 2.0);
std::cout << "Product: " << product << std::endl;

Void Functions

Functions that do not return a value have a return type of void. These functions typically perform operations but do not send a value back to the caller.


void printMessage() {
  std::cout << "Hello, World!" << std::endl;
}

printMessage();  // Function call

Function Parameters

Functions can take zero or more parameters. Parameters allow functions to accept input and perform operations based on that input.


void displaySum(int a, int b) {
  std::cout << "Sum: " << (a + b) << std::endl;
}

displaySum(10, 5);  // Output: Sum: 15

Default Parameters

C++ allows functions to have default parameter values. These are used when arguments are not provided for those parameters during a function call.


void greet(std::string name = "Guest") {
  std::cout << "Hello, " << name << "!" << std::endl;
}

greet();             // Output: Hello, Guest!
greet("Alice");      // Output: Hello, Alice!

Summary

Functions in C++ are essential for creating modular, reusable code. They help in breaking down complex tasks, improving code readability, and making maintenance easier. Understanding function declaration, definition, calling, and parameter handling is crucial for effective C++ programming.
