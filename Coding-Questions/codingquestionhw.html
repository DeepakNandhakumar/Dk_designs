Fencing the Ground

  • Input: Read integers a and b.
  • Calculate Perimeter: Compute c = 2 * (a + b).
  • Calculate Area: Compute d = a * b.
  • Output Perimeter: Print "The required length is c m".
  • Output Area: Print "The required area of carpet is d sqm".




Checking Alphabets

  • Input Character: Read a character n.
  • Check Alphabet: If n is between 'a' and 'z' or between 'A' and 'Z', proceed; else print "Not an alphabet".
  • Check Vowel: If n is 'a', 'e', 'i', 'o', 'u', 'A', 'E', 'I', 'O', or 'U', print "Vowel".
  • Check Consonant: If n is an alphabet but not a vowel, print "Consonant".
  • End Program: Terminate the program.




Odd or even

  • Input a number.
  • Divide number by two.
  • Check remainder.
  • If remainder is zero, output "even".
  • If remainder is not zero, output "odd".




Leap year or not

  • Input a year.
  • If year is divisible by 4, go to next step; otherwise, output "not a leap year".
  • If year is divisible by 100, go to next step; otherwise, output "leap year".
  • If year is divisible by 400, output "leap year"; otherwise, output "not a leap year".




Prime Number Check

  • Input a number n.
  • If n is less than 2, output "Not a prime number".
  • Check divisibility from 2 to sqrt(n).
  • If any number divides n, output "Not a prime number".
  • If no number divides n, output "Prime number".




Factorial Calculation

  • Input a number n.
  • Initialize result as 1.
  • For i from 1 to n, multiply result by i.
  • Output the result.




Fibonacci Series

  • Input a number n.
  • Initialize variables a and b to 0 and 1 respectively.
  • Print a and b.
  • For i from 2 to n, compute next number as sum of a and b.
  • Update a and b to next number and print the next number.




Largest of Three Numbers

  • Input three numbers a, b, and c.
  • Compare a with b and c.
  • If a is largest, output a.
  • Else compare b with c.
  • If b is largest, output b; else output c.




Sum of Digits

  • Input a number n.
  • Initialize sum to 0.
  • While n is greater than 0, add last digit of n to sum and remove last digit from n.
  • Output the sum.




Reverse a String

  • Input a string s.
  • Initialize an empty string result.
  • For each character in s, prepend it to result.
  • Output the reversed string result.




Factor of a Number

  • Input: Read an integer n.
  • Initialize: Set i to 1.
  • Check Factor: For each i from 1 to n, if n is divisible by i, print i.
  • Increment: Increase i by 1 and repeat until i > n.
  • End: Terminate the program.
