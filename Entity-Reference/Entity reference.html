HTML Entity References:

1. Less-than sign (<): &lt;

Where: Used to denote the start of an HTML tag.

When: Whenever you need to display a less-than sign without it being interpreted as the start of an HTML tag.

How: Use &lt; to display <.

Example: &lt;html&gt;

Output: <html

2. Greater-than sign (>): &gt;

Where: Used to denote the end of an HTML tag.

When: Whenever you need to display a greater-than sign without it being interpreted as the end of an HTML tag.

How: Use &gt; to display >.

Example: &lt;/html&gt;

Output: html>

3. Ampersand (&): &amp;

Where: Used to represent an ampersand in text.

When: Whenever you need to display an ampersand without it being interpreted as the start of an HTML entity.

How: Use &amp; to display &.

Example: AT&amp;T

Output: AT&T

4. Quotation mark ("): &quot;

Where: Used to enclose attribute values in HTML tags.

When: Whenever you need to display a quotation mark in attribute values or text.

How: Use &quot; to display ".

Example: &lt;a href=&quot;https://www.example.com&quot;&gt;Example&lt;/a&gt;

Output: <a href="https://www.example.com">Example</a>

5. Apostrophe ('): &apos;

Where: Represents an apostrophe in text.

When: Whenever you need to display an apostrophe.

How: Use &apos; to display '.

Example: It&apos;s a sunny day.

Output: It's a sunny day.

6. Non-breaking space: &nbsp;

Where: Creates a space that will not break into a new line.

When: Use to prevent unwanted line breaks.

How: Use &nbsp; to display a non-breaking space.

Example: Hello&nbsp;World

Output: Hello World

7. Copyright sign (©): &copy;

Where: Used to denote copyright on a piece of work.

When: Whenever you need to display a copyright symbol.

How: Use &copy; to display ©.

Example: &copy; 2024 Your Company

Output: © 2024 Your Company

8. Registered trademark sign (®): &reg;

Where: Indicates that a trademark is registered with the appropriate authorities.

When: Whenever you need to display a registered trademark symbol.

How: Use &reg; to display ®.

Example: Your Brand&reg;

Output: Your Brand®

9. Degree sign (°): &deg;

Where: Used to represent degrees, such as in temperature or angles.

When: Whenever you need to display a degree symbol.

How: Use &deg; to display °.

Example: 100&deg;C

Output: 100°C

10. Plus-minus sign (±): &plusmn;

Where: Represents a value that can be either positive or negative.

When: Whenever you need to display a plus-minus symbol.

How: Use &plusmn; to display ±.

Example: &plusmn;5%

Output: ±5%

11. Section sign (§): &sect;

Where: Used to reference sections of a document or legal code.

When: Whenever you need to display a section symbol.

How: Use &sect; to display §.

Example: Refer to &sect; 10.2 of the document.

Output: Refer to § 10.2 of the document.

12. Multiplication sign (×): &times;

Where: Used to denote multiplication or dimensions.

When: Whenever you need to display a multiplication symbol.

How: Use &times; to display ×.

Example: 5 &times; 3 = 15

Output: 5 × 3 = 15

13. Division sign (÷): &divide;

Where: Represents division.

When: Whenever you need to display a division symbol.

How: Use &divide; to display ÷.

Example: 10 &divide; 2 = 5

Output: 10 ÷ 2 = 5

14. Pound sterling sign (£): &pound;

Where: Denotes the currency of the United Kingdom.

When: Whenever you need to display a pound sterling symbol.

How: Use &pound; to display £.

Example: The cost is &pound;50.

Output: The cost is £50.

15. Euro sign (€): &euro;

Where: Represents the currency used by many European Union countries.

When: Whenever you need to display a euro symbol.

How: Use &euro; to display €.

Example: The price is &euro;20.

Output: The price is €20.

16. Addition Example

Where: Used to denote addition.

When: Whenever you need to display a plus sign.

How: The plus sign does not need a special entity reference; it can be used directly.

Example: 5 + 3 = 8

Output: 5 + 3 = 8

17. Subtraction Example

Where: Used to denote subtraction.

When: Whenever you need to display a minus sign.

How: Use &minus; to display −.

Example: 5 &minus; 3 = 2

Output: 5 − 3 = 2
